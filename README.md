# 💰 Expense Tracker

A simple Python-based Expense Tracker that helps users record and manage their daily expenses.

## 🚀 Project Overview

This project allows users to add expenses, view recorded expenses, and keep track of their spending through a simple command-line interface.

Built as part of my Python learning journey to strengthen concepts such as:
- Variables and Data Types
- Lists and Dictionaries
- Loops
- Conditional Statements
- User Input Handling
- Basic Data Management

## ✨ Features

✔ Add New Expenses  
✔ View Recorded Expenses  
✔ Track Expense Details  
✔ Interactive Command-Line Interface  
✔ Simple and Beginner-Friendly Design  

## 🛠 Technologies Used

- Python 3
